#### 2、Redis 的数据类型演进历程

  - Redis 1.0 (2009)：发布了奠定基础的5种核心数据类型：String (字符串)、Hash (哈希)、List (列表)、Set (集合) 和 Sorted Set (有序集合)。
  - Redis 2.2 (2011)：新增 BitMap (位图)，将字符串视为二进制位数组进行位操作，适合统计用户签到、在线状态等。
  - Redis 2.8 (2014)：新增 HyperLogLog，一种概率数据结构，用于以极小内存（约12KB）进行海量数据的基数（不重复元素个数）统计，如统计网站UV。
  - Redis 3.2 (2016)：新增 GEO (地理空间)，用于存储经纬度坐标，并支持计算距离和范围查询，是实现"附近的人"等功能的基础。
  - Redis 5.0 (2018)：新增 Stream (流)，一个功能强大的持久化消息队列，支持消费者组、消息回溯等，是构建可靠消息总线、事件溯源系统的理想选择。
  - Redis 7.4 (2025)：为满足AI应用需求，新增了对 BFLOAT16 和 FLOAT16 向量数据类型的支持，能有效减少内存占用并降低延迟。
  - Redis 8.0 (2026)：持续向AI领域拓展，新增了 Vector Set (向量集合) 数据结构
  - Redis 8.8 (2026.5)：增加了：
              -  原生的数组（Array）数据结构
              -  内置了基于 GCRA 算法的限流器。之前，第三方项目是通过 Lua 脚本在 Redis 中实现 GCRA 限流

  redis 的数据类型从最初的 5 种基础结构，发展到如今覆盖缓存、消息队列、地理空间、AI 向量检索等丰富场景的多元化数据模型。


#### 3、Redis 8.0 及模块生态

Redis 8.0 是一个重要的里程碑，它将原本需要以模块形式加载的功能（如搜索、JSON、时序、布隆过滤器等）集成到了核心。这意味着在 Redis 8.0 中，你还可以直接使用以下数据类型（早期版本需加载对应模块）：

  - JSON：原生支持 JSON 文档的存储和操作。
  - Time Series (时序数据)：专为处理时间序列数据设计。
  - Bloom Filter / Cuckoo Filter (布隆/布谷鸟过滤器)：用于高效判断一个元素是否在集合中。
  - Top-K：用于统计出现频率最高的 K 个元素。
  - Count-Min Sketch：一种概率数据结构，用于频率估计。
  - T-Digest：用于计算百分位数等统计信息
  - GCRA： 从 Redis 8.8 版本开始，内置了基于 GCRA 算法的限流器，限制 多少时间（窗口时间）内最大请求数量。
