
#### 1、rdb 文件解析参考

  rdr工具的核心部分就是rdb文件解析，作为开发者，我们可以通过以下几个途径来掌握相关知识：

  1. 大部分 rdb 文件的解析都是按照:
     - https://github.com/sripathikrishnan/redis-rdb-tools/wiki/Redis-RDB-Dump-File-Format
     - https://github.com/cupcake/rdb

  2. Redis迁移工具RedisShake（语言golang），由阿里云 Tair 团队长期维护， 从 RDB 文件中读取数据写入目标端，我们可以参考它这块的代码。
     项目地址：https://github.com/tair-opensource/RedisShake
     rdb.go源码地址：https://github.com/tair-opensource/RedisShake/tree/v4/internal/rdb

  3. RDB 文件格式说明：https://www.cnblogs.com/Finley/p/16251360.html 

  4. redis 源码
```
  rdb.c 文件：https://github.com/redis/redis/blob/7.0-rc3/src/rdb.c     // RDB 文件读写，行1736：robj *rdbLoadObject
  rdb.h 文件：https://github.com/redis/redis/blob/unstable/src/rdb.h   // RDB version、RDB object types 等定义

```

小结：
        - Redis 官网：https://github.com/redis/redis/blob/unstable/src/rdb.h
        - RedisShake：internal/rdb/
                                                   |-- rdb.go       # rdb文件解析的主文件
                                                   |-- /types/interface.go  #  （底层数据存储结构，也称为底层编码） 类型的接口定义文件
---

time_t rdbLoadTime(rio *rdb) {
    int32_t t32;
    if (rioRead(rdb,&t32,4) == 0) return -1;    // 从 rio 对象 r 中读取 len 字节到 buf，这里是读4个字节的数据
    return (time_t)t32;
}
